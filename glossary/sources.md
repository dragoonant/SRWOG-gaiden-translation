# Sources

Primary canon per the brief: the English used by the two PS2 fan patches (Kingcom's *OG: Original Generations* v1.2, Dec 2020; camd11/"Creamhouse" *OG Gaiden* v0.2.9, Jul 2026). Neither patch publishes a glossary or script dump, so the Akurasu wiki (the user-designated source) supplies nearly every English form here. Where Akurasu pages disagree with each other, both forms are recorded in the TSV `notes` column and in `gaps.md`.

## Honorifics and style observations

**Kingcom OGs patch (PS2, 2020):** No readme, script dump, or screenshot of Kingcom's dialogue could be reached (romhacking.net and GameFAQs are behind bot-verification; the review at romhacking.net/reviews/6525 was unreadable). Therefore **whether Kingcom kept -san/-kun/-sama is not established by any source in this pass.** Indirect evidence only: (a) the Akurasu OGs Spirit Commands page, which cross-references the fan translation's effect text, uses Valor/Flash/Persist/Wall/Focus/Bullseye/Attune/Zeal/Vigor/Guts — distinct from both Atlus GBA names (Strike/Alert) and the OGG wiki page names, so these are the most likely Kingcom forms; (b) camd11 states its OGG patch follows Kingcom's terminology and mimics Kingcom's inline speaker format and proportional font. Treat "Kingcom style" below as inferred through camd11.

**camd11 OG Gaiden patch (PS2, 2026), observed directly from its screenshots and changelog:**
- Speaker names are inline: `Name: dialogue` (e.g. `Hugo: Captain! Heat and movement signatures ahead! Count six!`). The README says this matches Kingcom's OG1 patch and the original Japanese game; Japanese 「」 brackets are removed.
- Characters are addressed by rank/role in English ("Captain!"); no Japanese honorifics appear in any of the sampled lines (Folia, Hugo, Albero, Kota). Sample size is small (about six lines), so this is suggestive, not conclusive.
- Register is casual, contraction-heavy, idiomatic ("Welp -- looks like we're cleaning up after that bunch again this time too.", "kickin' butt!", "…So they've come."). Em-dashes are rendered as a double hyphen `--`, ellipses as `…`.
- Name forms seen in-game: "Folia" (not Foglia), "Kota" (not Kouta), "Albero", "Hugo", "Eric Wang", nickname "Compatikaiser".
- Unit names: Title Case, model abbreviations kept ("MP Gespenst Mk-II"). Terrain names are short single words ("Wastes" for 荒野); terrain/size letters A/B/C/S and S/M/L; terrain columns abbreviated Ai/La/Se/Sp; movement type "Lnd"/"Land".
- UI: menu labels Title Case (Ally Unit List, Upgrade Parts, Equip Slot, Active Spirit Commands, Support Attack/Support Defend, Total Movement, Movement Type); stat labels abbreviated (Mob, Mel, Skl, Rng, Def, Acc, Eva %, NEXT); battle/status banners in ALL CAPS ("EXPERT", "EVADE", "DISABLED!", "TWIN COMMAND", "BACKLOG"); spirit names truncated to 4 letters in menus ("Focs", "Guts") and 2–3 letters in the legend (Va, Fl, Gu, Ir, Fo, St, Ac, Aw, Mc, Sn, Se, Lu, Ga, As, Rp, Fs, Ds, So, Co, Sy, Drv). "Skill Point acquired. All pilots +5PP." Objectives are numbered with dash bullets ("1. Destroy all enemies."). Empty slots use "-----". Spirit scope line 自/単 left in Japanese.
- Attack-name casing: not observable in the available OGG screenshots (no attack list shown). The Akurasu convention, which camd11 claims to share with Kingcom, is Title Case with hyphenated model prefixes (T-Link Knuckle, Hi-Zol Launcher (Spread), 5-Barrel Chaingun, Oxtongue Launcher W, Type 0 Colossal Blade, Unstoppable TK Burst Slash). Japanese-origin attacks are mostly translated (竜巻斬艦刀 → Tornado Blade / Tornado Zankanto; 天上天下一撃必殺砲 → Unstoppable HTB Cannon; 龍虎王 attacks → Magma Vassal, Mountain Pressure, Wrathcleaver; 参式斬艦刀 → Type 3 Colossal Blade), with a few romanized exceptions (Bakuraifu, Shishioh Blade, Kishin Mougeki Ken).
- BGM track names in camd11 follow "Kingcom OG1 track-name canon" at full length.

**Zone of Heroics script (not a patch):** drops honorifics, uses English ranks ("Lt. Irm", "Corporal Nanbu", "Lt. Col."), inconsistent abbreviation of ranks. Included only as a style datapoint from the same fan community.
